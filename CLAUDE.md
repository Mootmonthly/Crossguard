# Crossguard — notes for Claude

Social fantasy extraction PvP game. Unreal Engine 5.8, C++ with the Gameplay Ability System.

## Working rules (from the owner)

- Implement the owner's rulings; ask about real ambiguities. Flag every assumption you make, in the reply
  and as "(placeholder)" / "Assumed" in `docs/design-decisions.md`.
- Commit and push every change to `foundation/core-rules`. No pull requests unless asked.
- Replies: short and plain ("caveman" style is fine). Skills in brackets: [Neckbite].
- Quality first; review work (yours and helpers') before calling it done.
- `docs/design-decisions.md` is the source of truth for rulings; it overrides the Drive design docs.

## Layout

- `Source/CrossguardRules`: engine-free rules (plain C++), unit-tested in `Tests/CrossguardRules`.
- `Source/Crossguard`: the game module. Automation tests in `Source/Crossguard/Private/Tests`
  (`Crossguard.*`; scenario framework `CrossguardScenario.h`, guide in `docs/editor-tests.md`).
- `Data/`: JSON source data. `*Table.json` files are generated by `Tools/export_*_table.py`; don't edit them by hand.
- `Tools/`: validators, exporters, editor scripts. `Tools/MobForge`, `Tools/SkillForge`: web editors synced by script.
- `docs/`: rulings, schemas, roadmap, `next-build-checklist.md`, `editor-tests.md`, `pc-session.md`.

## Commands

- Checks without Unreal: `Tools/run_checks.sh` (validators, export checks, rules unit tests).
- On the Windows PC (see `docs/pc-session.md`): build the editor, run `Tools\editor_setup.bat`
  (data tables and references), then `Tools\run_editor_tests.bat` (headless automation tests,
  report in `Saved\EditorTests\summary.txt`). Close the Unreal editor before command-line builds.

## Code conventions

- Unity builds: names in a .cpp's anonymous namespace must not collide with names a test file pulls in
  with `using namespace`. Give file-local helpers a per-file namespace.
- Shadowed variables are errors in Unreal; avoid them.
- Server-authoritative: every client request is validated on the server (`docs/anti-cheat.md`).
- Match the surrounding style and comment density.
